# Manual Arena acceptance

Run these on the actual Windows show machine before live use. Start with strobe off, low brightness, and no audience facing the output. Automated host tests do not replace Arena acceptance.

1. Add a dedicated plugin search directory, restart Arena, and verify Source appears in Sources and Effect in Effects. Check the host version is 7.3.0 or later. Confirm Wire is not involved.
2. Play Source at ID 1 / port 12000. Confirm controller Connected comes from status replies. Enter multiline Latin, Sinhala, Arabic, Japanese and emoji with suitable installed fonts. Check shaping, wrapping, bold/italic, opacity, alignments, font size, spacing, position, rotation, scale, outline and glow at the composition's real resolution.
3. Place a checkerboard/video behind the source. Check clean transparency and antialiased edges, including opacity 0 and empty text. Enable a solid background and confirm its RGBA/opacity, then disable it.
4. Add Effect to a moving clip. Verify one-input video remains visible under text; text opacity changes the overlay, not original video. Test on a clip with alpha, padded texture dimensions, and several composition resolutions. Toggle Blackout: the original clip must pass through unchanged, including alpha.
5. Create two source instances with IDs 1 and 2. Target each and confirm only it changes. Deliberately duplicate IDs: status must report 2 and all controls must be rejected. Give the duplicate a unique ID and reconnect. Repeat for Effect on port 12001. Delete and recreate instances; confirm no ghost IDs and the port reopens when the last instance is removed.
6. Test a deliberate port conflict with another UDP listener. No misleading Connected state should appear. Change `PULSETEXT_SOURCE_PORT` or `PULSETEXT_EFFECT_PORT` before relaunching Arena, update the desktop destination and verify recovery. Test two Arena processes using separate ports.
7. Test every animation with Restart, at different frame rates and speeds. Include speed zero, typewriter with a long Unicode message, animation transitions, and timeline/clip pause/resume. Speed should depend on elapsed time rather than frame count. Check resize, clip replacement and clean Arena shutdown.
8. Select a real microphone/line input, Start input, and check level/band meters. Map bass-weighted energy to scale/glow/brightness/shake. Play bass, voice and treble-rich material. Adjust threshold, sensitivity, attack and release. Unplug input: show unavailable/stale status and return mappings to zero; refresh/reselect/restart to recover.
9. Select a [System loopback] endpoint, play Windows audio and verify capture. Test output-device switching/disconnection and mono/stereo endpoints. Devices without loopback support should leave microphone operation usable.
10. Verify Rate, manual BPM/subdivision and Audio transient flash modes separately. Test Text, Background and Whole output targets at low intensity. Confirm Stop Strobe preserves text and Blackout bypasses the generated layer. Verify Escape always stops even while typing; other shortcuts must not fire while typing.
11. Enable a slow strobe, then kill the desktop process or block UDP. After the configured timeout, rendering must stop flashing. Resume only heartbeat/audio traffic: it must remain disarmed. Explicitly enable in a new state to rearm. Test source and effect, including a suspended/resumed clip.
12. Save/load/export/import a preset with Unicode and non-default settings. Confirm exact settings restore while strobe and blackout remain off. Restart the app and check local presets persist. Reopen an Arena composition and reapply the matching preset; OSC text is not stored by Arena.
13. Exercise Arena numeric automation alongside incoming OSC. Verify multiplicative precedence and Strobe gate/Blackout OR behavior described in OSC.md. Run sustained playback at the actual resolution, observe CPU/GPU use, and inspect other effects for any GL state corruption.

Record Windows/GPU driver, Arena version, resolution, fonts, selected audio endpoint, plugin build hash and each result. Minimum-version support requires a separate run on Arena 7.3.0.
